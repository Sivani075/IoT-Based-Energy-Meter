## Project Description
This project is a smart IoT-based energy meter developed using ESP32, OLED display, potentiometer simulation, and Blynk cloud platform.

The system monitors current and power consumption in real time and displays values both on OLED display and Blynk dashboard.

## Features
- Real-time energy monitoring
- ESP32 WiFi connectivity
- OLED display output
- Blynk cloud integration
- Overload LED indication
- Live dashboard monitoring

## Components Used
- ESP32
- OLED SSD1306
- Potentiometer
- LED
- Blynk IoT Platform

## Software Used
- Arduino IDE
- Wokwi Simulator
- Blynk Cloud

The project successfully displays:
- Current values
- Power values
- Real-time dashboard updates
